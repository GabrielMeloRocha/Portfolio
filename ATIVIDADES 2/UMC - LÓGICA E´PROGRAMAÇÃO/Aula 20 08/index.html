CSS


CSS significa Cascading Style Sheets (Folhas de Estilo em Cascata),
É uma linguagem de estilo usada para definir a aparência visual de páginas da web.


Vantagens do CSS:

Separação de conteúdo e estilo: O CSS permite manter o HTML limpo e focado na estrutura, enquanto o design é gerenciado separadamente.

Reutilização de código: Um único arquivo CSS pode ser aplicado a várias páginas, facilitando a manutenção.

Responsividade: Com recursos como media queries, é possível adaptar o layout para diferentes dispositivos e tamanhos de tela.

Consistência visual: Garante que o design seja uniforme em todo o site.

Melhor desempenho: Sites com CSS bem estruturado carregam mais rápido, pois o navegador pode reutilizar o arquivo de estilo.

Desvantagem do CSS:

Compatibilidade entre navegadores:
Nem todos os navegadores interpretam o CSS da mesma forma.
Propriedades mais novas podem não funcionar em versões antigas de navegadores, exigindo prefixos (-webkit-, -moz-, etc.) ou fallbacks.

Falta de segurança:
O CSS é uma linguagem de estilo, não de programação, e pode ser facilmente inspecionado e copiado.
Não há como “proteger” o código CSS de forma efetiva.

Manutenção complexa em projetos grande:
Em projetos sem organização (sem uso de metodologias como BEM, SMACSS ou CSS Modules), o código pode ficar confuso e difícil de manter.
Alterar um estilo pode afetar várias partes da aplicação de forma inesperada.

Dependência da estrutura HTML:
O CSS depende diretamente da marcação HTML.
Mudanças na estrutura do HTML podem quebrar estilos existentes.

Limitações funcionais:
CSS puro não possui lógica condicional ou cálculos complexos (embora o CSS moderno tenha variáveis e funções limitadas).
Para estilos dinâmicos mais avançados, é necessário usar preprocessadores como Sass ou Less.
